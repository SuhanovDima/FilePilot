# Начальный промпт для Codex — FilePilot

Ты работаешь как senior Java AI engineer. В текущей папке должен быть `FILEPILOT_SPEC.md` и `AGENTS.md`. Сначала прочитай оба файла полностью. Твоя задача — РЕАЛЬНО НАПИСАТЬ работающий open-source pet-проект FilePilot, а не составить ещё один план.

Стек: Java 21, Maven, Spring Boot 4.0.x, Spring AI 2.0.2, SQLite, Thymeleaf/HTMX, JUnit. Работает на Intel Mac 32 GB RAM и Windows; локальная LLM через OpenAI-compatible endpoint Ollama или llama.cpp, но приложение должно стартовать без LLM и работать по детерминированным правилам.

Работай в этапах P0–P5 из спецификации. **Приоритет первого прогона: P0–P2 — вертикальный срез allowlisted workspace -> scan -> rule classifier -> preview plan -> explicit confirmation -> safe move -> journal -> undo, API и полноценные тесты.** Не пытайся сделать сразу RAG и MCP: они запланированы после MVP. После успешной реализации P0–P2, если ресурсы позволяют, переходи к P3–P5 (LLM, UI, CI/docs).

Критично: ни одна операция с пользовательскими файлами без подтверждения, никакого удаления/перезаписи/выхода за разрешённый корень, только temp fixtures в тестах. Модель не выполняет файловые инструменты и не задает пути: она даёт ограниченные категории, валидируемые в Java. Не запускай никакие операции на реальном `~/Downloads`.

Перед кодированием проверь версии реальных Maven-зависимостей и свойства Spring AI по документации; не выдумывай API. В каждом этапе запускай Maven tests и исправляй сборку. Создай Maven Wrapper и всю необходимую структуру проекта, README на русском, license Apache-2.0, CI для Linux/Windows, demo fixture scripts. Если проект уже существует — оцени текущее состояние и продолжи без перезаписи пользовательских изменений.

При завершении дай конкретный отчет: какие требования выполнены, какие файлы созданы, команды и реальные результаты тестов, что осталось и как безопасно запустить demo. Не утверждай, что проверил Intel Mac или Windows, если реально не запускал там тесты. Не делай git push без прямой просьбы пользователя.

**Начинай реализацию сейчас.**
